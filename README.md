# UPI Insights 2024 📊

An exploratory data analysis (EDA) project exploring 250,000 synthetic UPI transactions from 2024 using Python.

The goal of this project was to practise data inspection, aggregation, data visualization, and interpreting patterns in transaction data.

## 🎯 Objectives

This project explores five questions:

1. How do transaction amounts vary across age groups and merchant categories?
2. How do fraud-flag counts and rates differ across merchant categories?
3. How does transaction activity vary across age groups and merchant categories?
4. What patterns can be observed in fraud flags over time?
5. How do transaction failure rates vary by device, network, transaction type, and time?

## 🔎 Key Findings

- **Transaction amounts:** The distribution was right-skewed, with lower-value transactions occurring more frequently than high-value transactions.
- **Transaction failures:** Approximately 4.95% of transactions failed in the dataset.
- **Transaction type:** Failure rates were similar across transaction types, ranging from approximately 4.88% to 5.09%.
- **Weekday vs. weekend:** The weekend failure rate was approximately 5.09%, compared with 4.89% on weekdays.
- **Fraud flags:** Transport had the highest fraud-flag rate among merchant categories, while Grocery had the highest number of flagged transactions.
- **Age groups:** Transaction totals and average amounts varied across age groups and merchant categories.

These findings describe the generated dataset, not verified real-world UPI behaviour.

## ⚠️ Dataset Limitations

The dataset was generated using a synthetic transaction generator available on Kaggle.

The transaction amounts, demographic patterns, transaction statuses, and fraud flags are simulated. In particular, fraud flags are randomly assigned by the generator rather than derived from verified fraud cases.

Therefore, the analysis should not be used to draw conclusions about actual UPI users, real fraud prevalence, or real-world payment behaviour.

## 🚀 How to Run

1. Clone or download this repository.
2. Obtain the dataset from its original source, subject to its licensing and usage terms.
3. Place `upi_transactions_2024.csv` in the project directory.
4. Install the required libraries:

   ```bash
   pip install pandas numpy matplotlib seaborn jupyter
   ```

5. Start Jupyter Notebook:

   ```bash
   jupyter notebook
   ```

6. Open `01_data_inspection.ipynb` and run the notebook cells.
